# نشر الاستبيان باستخدام GitHub Pages وربطه بـ Google Sheets

**هام:** هذا إصدار مخصص لواجهة الاستبيان العامة، ولا يحتوي على لوحة الإدارة السابقة المبنية بخادم Python. تعديل القطاعات والألوان والنصوص يكون في `config.json` على GitHub، ومتابعة البيانات وتصديرها تتم من Google Sheets. لا ترفع ملف قاعدة البيانات `survey.sqlite3` أو كلمات المرور إلى GitHub.

## أولا: تجهيز Google Sheet
1. افتح https://sheets.google.com وأنشئ ملفًا جديدًا باسم «نتائج استبيان مسارات الرعاية».
2. اختر **Extensions > Apps Script**.
3. الصق محتوى `google_apps_script/Code.gs` في ملف `Code.gs` واحفظه.
4. اختر **Deploy > New deployment > Web app**، ثم **Execute as: Me** و **Who has access: Anyone** (إن سمحت سياسة حسابك). وافق على الأذونات المطلوبة وانسخ الرابط المنتهي بـ `/exec`.
5. في حال تعديل سكربت Apps Script مستقبلاً، حدّث الإصدار المنشور من **Manage deployments > Edit > New version**.

## ثانيا: ربط الرابط بالاستبيان
1. افتح `config.json` واستبدل القيمة `PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` بالرابط المنتهي بـ `/exec`.
2. عدل أسماء القطاعات تحت `sectors`، والعناوين والألوان تحت `appearance` متى احتجت.
3. احتفظ بعلامات التنصيص والفواصل. تحقق من JSON قبل حفظه.

## ثالثا: GitHub Pages
1. أنشئ مستودعًا جديدًا في https://github.com/new وليكن `care-awareness-survey`.
2. اجعله Public إذا كنت تستخدم GitHub Pages المجاني لحساب شخصي. لا تضع فيه أي ردود أو بيانات شخصية أو كلمات مرور.
3. ارفع ملفات **محتويات هذا المجلد** إلى جذر المستودع: `index.html`, `config.json`, `static/`, وغيرها. لا ترفع ملف ZIP دون فكّه.
4. من **Settings > Pages** اختر **Deploy from a branch** ثم `main` و `/ (root)` واضغط Save.
5. ستحصل على رابط شبيه `https://USERNAME.github.io/care-awareness-survey/`.

## رابعا: الاختبار المهم
1. افتح رابط GitHub Pages من جوال مختلف.
2. أرسل ردًا تجريبيًا يتضمن مسارين؛ يجب أن تظهر رسالة تأكيد من الخادم.
3. افتح Google Sheet وابحث عن تبويبي «الردود» و«المسارات والمنسقون».
4. تأكد من وجود استجابة واحدة وسطرين للمسارين. ثم اختر File > Download > Microsoft Excel (.xlsx).
5. إذا استمر «جارٍ حفظ الاستجابة» أكثر من 25 ثانية، فلا تعِد الإرسال قبل مراجعة الجدول؛ فقد تكون الاستجابة حُفظت دون وصول إشعار التأكيد.

## تحذيرات وحدود
- **GitHub Pages لا يشغّل Python ولا يدعم لوحة تحكم V3.1 القديمة**. هذا تحويل إلى موقع ثابت + Google Apps Script.
- رابط Apps Script عام لكي يتمكن المشاركون من الإرسال. لا تستخدمه لتخزين معلومات مرضى أو بيانات حساسة، ولا تشارك Google Sheet علنًا.
- يجب ألا يكون لدى المشاركين إذن تحرير Google Sheet؛ سكربت Apps Script هو الذي يسجل الاستجابات نيابة عن المالك.
- الاسم ورقم القطاع ونصوص المسارات بيانات وظيفية/شخصية؛ راعِ سياسة جهة عملك ولو كانت التجربة غير رسمية.
- الإصدارات المجانية لها حصص استخدام وشروط، وليست ضمانًا دائمًا بلا قيود.
- الإغلاق التلقائي ولوحة الإدارة عبر الويب غير متوفرين في هذه النسخة؛ يتطلبان إضافة منفصلة.
- إذا واجه المتصفح منعًا للتواصل بين GitHub وApps Script أو لم تصل رسالة نجاح، اختبر عملية النشر من البداية قبل تعميم الرابط. هذه الحزمة لم تخضع لاختبار تكاملي مباشر مع حسابك في Google.
